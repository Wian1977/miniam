# miniam

终端里的 Apple Music 遥控器，顺带把封面和频谱画出来。

```
┌────────────────────────────────────────┐
│                                        │
│           ▄▄▄▄▄▄▄▄▄▄▄▄                 │   封面
│           █████████████                │   频谱
│           █████████████                │
│                                        │
│   ♪ Shape of You · Ed Sheeran          │   歌名
│   ▁▂▃▅▆▇▆▅▃▂▁▂▃▄▅▆▇▆▅▃▂▁          │   频谱
└────────────────────────────────────────┘
```

启动就开始播。空格暂停，再按继续。

## 封面

封面用终端的 24-bit 真彩色还原。每个字符格能显示两种颜色，
这一格的两个颜色取自原图在该处的采样，在 RGB 空间里最接近原图。

整幅封面因此是连续的画面，格与格之间看不出接缝。

## 频谱

取系统混音器里 Firefox 自己输出的那一路音频。别的应用出声时，频谱不受影响。

## 后台浏览器

Apple Music 网页版的 DRM 只有真实浏览器加 Widevine 才能解。miniam 在后台跑一个无头
Firefox，用你已有的登录状态取音频 —— 账号、歌单、音质都和平时一样。

## 声音去向

浏览器的声音先进一个虚拟输出端，再回送到你原本的输出设备。系统默认输出保持原样，
别的应用也不会被静音。

## 资源占用

后台浏览器关掉了站点隔离和不必要的解码，
网页版背景里循环播放的氛围视频也压住了 —— 那东西在 4 核机器上能吃掉半个 CPU。

## 用法

```bash
miniam
```

第一次会弹出浏览器让你登录 Apple Music，登录一次就长期有效。

| 键 | |
|---|---|
| `空格` | 播放 / 暂停 |
| `n` | 下一首 |
| `b` | 上一首 |
| `c` | 换频谱样式 |
| `d` | 页面诊断 |

个人电台是无限流，没有上一首可退，这时按 `b` 会提示。

## 需要什么

- Linux + 终端（PipeWire / PulseAudio 都行）
- Firefox 或 Chrome，带 Widevine CDM
- Rust 工具链（构建用）

```bash
cargo build --release
```

## 其他

解码、加密、订阅都由 Apple Music 处理，miniam 只做取流和显示。声音质量取决于你的账号。

封面渲染用到少量 Unicode 象限字符（`▘ ▝ ▀ ▖ ▌ ▞ ▛ …`）。
多数终端里它们是等宽的，部分 CJK 语言环境下可能被当作双宽字符渲染。
Ghostty / Kitty / WezTerm / Alacritty 下正常。

## 许可

代码可自由取用。内置点阵字库的许可见 `assets/README-unifont.txt`。
