# miniam

在终端里听 Apple Music。敲一行命令，音乐就起来了；封面、歌名、频谱都留在同一个窗口里，手不用离开键盘。

```
┌────────────────────────────────────────┐
│                                        │
│           ▄▄▄▄▄▄▄▄▄▄▄▄                 │   封面
│           █████████████                │   频谱
│           █████████████                │
│                                        │
│   ♪ Shape of You · Ed Sheeran          │   歌名
│   ▁▂▃▅▆▇▆▅▃▂▁▂▃▄▅▆▇▆▅▃▂▁          │   频谱
└────────────────────────────────────────┘
```

适合写代码、看日志、跑构建的时候开着。不用另开浏览器窗口，也不用为切歌去点网页。

启动后自动接着播放，空格暂停，再按继续。

## 打开能看到什么

从上到下是专辑封面、正在播的歌名和艺人、进度、随音乐起伏的频谱，最下面一行是队列状态。

封面按终端字符格还原成 24-bit 真彩色，颜色取自原图；标题用点阵字，小字号也清楚。频谱读的是这首歌自己的声音，旁边有别的程序出声时不会跟着乱跳。

## 声音和机器

歌从你平时用的音箱或耳机出来，系统默认输出保持原样，别的程序该出声还出声。用的还是你自己的 Apple Music 账号，歌单和音质跟网页里一样，登录一次就长期有效。

后台的浏览器也调过：关掉站点隔离和用不上的解码，网页里循环播放的氛围视频压住了，机器不会因为听首歌就热起来。

## 用法

```bash
miniam
```

| 键 | |
|---|---|
| `空格` | 播放 / 暂停 |
| `n` | 下一首 |
| `b` | 上一首 |
| `c` | 换频谱样式 |
| `d` | 页面诊断 |

个人电台是无限流，没有上一首可退，这时按 `b` 会提示。

实际使用时的窗口录了一段：[assets/demo.mkv](assets/demo.mkv)（37 秒）。

## 需要什么

- Linux + 终端（PipeWire / PulseAudio 都行）
- Firefox 或 Chrome，带 Widevine CDM
- Rust 工具链（构建用）

```bash
cargo build --release
```

环境变量、音频链路、封面渲染和排障写在 [docs/DETAIL.md](docs/DETAIL.md)。

## 其他

解码、加密、订阅都由 Apple Music 处理，miniam 只做取流和显示。声音质量取决于你的账号。

封面渲染用到少量 Unicode 象限字符（`▘ ▝ ▀ ▖ ▌ ▞ ▛ …`）。多数终端里它们是等宽的，部分 CJK 语言环境下可能被当作双宽字符渲染。Ghostty / Kitty / WezTerm / Alacritty 下正常。

## 许可

代码可自由取用。内置点阵字库的许可见 `assets/README-unifont.txt`。
