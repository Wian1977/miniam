# miniam

在终端里的一台 Apple Music 遥控器 + 音乐可视化器。

```
┌────────────────────────────────────────┐
│                                        │  ← 封面：专辑图真彩还原（24-bit）
│           ▄▄▄▄▄▄▄▄▄▄▄▄                 │
│           █████████████                │  ← 频谱：跟着声音跳
│           █████████████                │
│                                        │
│   ♪ Shape of You · Ed Sheeran          │  ← 歌曲信息
│   ▁▂▃▅▆▇▆▅▃▂▁▂▃▄▅▆▇▆▅▃▂▁          │  ← 频谱
└────────────────────────────────────────┘
```

打开就播。按空格暂停，再按继续。

## 特色

**封面是真彩，不是色块拼图**
专辑封面直接用终端的 24-bit 真彩色还原 —— 每一格都是精确算出来的前景色 + 背景色，
两个颜色在 RGB 空间里最接近原图。不是滤镜、不是 ASCII art。

**频谱是真的频谱**
读的是系统混音器里**被控的那一路**音频（Firefox 自己的输出），不是麦克风、不是系统总输出。
所以你放视频的时候它不会乱跳。

**后台是个真浏览器**
Apple Music 网页版的 DRM 只有真浏览器 + Widevine 能解。所以 miniam 在后台跑一个无头
Firefox，用它的登录态拿音频 —— 你的账号、你的歌单、你的音质，一点没减。

**它不碰你的声音**
只加一个虚拟输出端接住浏览器的音频，再原样送回你平时的输出设备。
不改变系统默认输出，不抢你的声卡，不静音别的应用。

**安静**
终端里跑的东西不该抢 CPU。后台浏览器被专门调过 —— 关掉不必要的解码、
压住网页版那些背景视频动画。整机负载降一个数量级。

## 用法

```bash
miniam
```

第一次会弹出浏览器让你登录 Apple Music，登录一次就长期有效。

| 键 | |
|---|---|
| `空格` | 播放 / 暂停 |
| `n` | 下一首 |
| `b` | 上一首（个人电台是无限流，没有上一首可退） |
| `c` | 换频谱样式 |
| `d` | 页面诊断 |

进界面就自动起播，不用按任何键。

## 需要什么

- Linux + 终端（PipeWire / PulseAudio 都行）
- Firefox 或 Chrome，**带 Widevine CDM** —— Apple Music 网页版的 DRM 硬要求
- Rust 工具链（构建用）

```bash
cargo build --release
```

## 一点说明

它是个遥控器 + 可视化器，不是播放器：解码、加密、订阅都在 Apple Music 那边。
音频质量取决于你的账号，miniam 只是把声音搬进终端、再搬出去。

封面渲染用到少量 Unicode 象限字符（`▘ ▝ ▀ ▖ ▌ ▞ ▛ …`）。
这些字符在多数终端里是等宽的，但在部分 CJK 语言环境下可能被当作双宽字符渲染。
Ghostty / Kitty / WezTerm / Alacritty 下正常。

## 许可

代码可自由取用。内置的 GNU Unifont 点阵字库与 Iosevka 字库见
`assets/README-unifont.txt`（各有自己的许可）。
