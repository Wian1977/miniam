miniam

Apple Music in your terminal: true-color album art, a live spectrum, and keyboard controls in one window.

在终端里听 Apple Music：真彩封面、动态频谱和键盘控制，都在同一个窗口。

miniam in a terminal — cover art, track info and spectrum / 终端里的 miniam：封面、歌曲信息与频谱

What it does / 功能

  • Start playback with one command and keep your hands on the keyboard.
  • True-color album art rendered with Unicode quadrant blocks.
  • Live spectrum with several styles that follow the music.
  • Space to pause, n for next, b for previous, c to change the spectrum, d for page diagnostics.
  • Audio still comes from your usual speakers or headphones; the system default output stays as it is.
  • The spectrum reads only its own audio stream, so sound from other apps does not move it.
  • A hidden Firefox or Chrome window plays the official web player in the background.
  • 一行命令开始播放，手不用离开键盘。
  • 用 Unicode 象限字符渲染 24-bit 真彩专辑封面。
  • 多种频谱样式，跟随音乐起伏。
  • 空格暂停，n 下一首，b 上一首，c 切换频谱，d 查看页面诊断。
  • 声音仍从你原来的音箱或耳机出来，系统默认输出保持原样。
  • 频谱只读取自己这一路音频，别的程序出声不会让它乱跳。
  • 后台用隐藏的 Firefox 或 Chrome 窗口播放官方网页播放器。

Install / 安装

Linux x86_64, prebuilt. No Rust toolchain needed.
Linux x86_64 预编译包，不需要 Rust 工具链。

tar.gz .deb All releases / 全部版本 Gitee 镜像下载

Homebrew: brew install Wian1977/miniam/miniam
Nix (NUR): nix-env -f '<nixpkgs>' -iA nur.repos.Wian1977.miniam

From source: cargo build --release && ./target/release/miniam
源码构建：cargo build --release 后运行 ./target/release/miniam。

Requirements / 运行要求

  • Linux with PipeWire or PulseAudio, plus pactl / parec.
  • Official Firefox or Chrome. The first launch opens a browser window so you can sign in to Apple Music once.
  • A terminal with 24-bit color and Unicode support.
  • Linux，需要 PipeWire 或 PulseAudio，以及 pactl / parec。
  • 官方 Firefox 或 Chrome。首次启动会弹出浏览器窗口，登录一次 Apple Music 即可。
  • 支持 24-bit 真彩与 Unicode 的终端。
